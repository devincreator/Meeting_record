# 会议纪要质量检查清单

## 素材与拆分
- [ ] 核实本次允许使用的原始材料，不引入未请求的外部内容。
- [ ] 按主讲人、独立访谈、不同机构分场，日期与机构不串场。
- [ ] 去除主持串场、签约、合影等非主讲内容（用户另有要求除外）。
- [ ] 缺失录音只按授权使用其他场次资料，不伪装缺失的原话。

## 信息覆盖
- [ ] 关键数字全部有归属：产能、产量、销售量、价格、成本、开工率、利润、资金、时间。
- [ ] 技术与工艺、商业模式、客户、竞争、经营变化的原因、项目规划与条件已完整保留。
- [ ] 核心要点≤5条，详细纪要≤9节；没有为了控制章节而省略重要信息。
- [ ] 详细纪要是连续自然段，不是机械的问答逐字稿或极短摘要。

## 事实准确
- [ ] 术语纠错有原始上下文支撑；不猜公司名、产品名、工艺名。
- [ ] 单位、时期、对应产品和数值合理配对；相互冲突的数字不自行调和。
- [ ] 历史客户询价、当前报价、成交价分别表述。
- [ ] 车间成本、完全成本、含税/不含税、毛利润、净利润不混淆。
- [ ] 环评、安评、试产许可、投料、试生产、验收、转固、达产不混淆。
- [ ] 意向客户、询盘、合同订单不混淆；规划和已实现不混淆。

## 文体
- [ ] 直接陈述结论，不写“公司认为”“公司表示”“交流中提到”等冗余引导。
- [ ] 没有口语、寒暄、追问、主持人过场、大段原话。
- [ ] 没有额外的“注意事项”“风险提示”、外部推断、投资建议或自造数据。
- [ ] 关键不确定性仅在原文存在时准确融入正文。

## 文件交付
- [ ] 用户要求DOCX时：标题与正文纯黑；无段首黑色方点或列表符号。
- [ ] 字体、行距、段距一致，中文文字正常显示，标题不会截断或单独悬在页尾。
- [ ] 文件已真实保存，并经过实际检查；链接对应已验证的文件。
- [ ] 未把用户的原始私密材料上传到公共仓库。
